## 零、版本基线（全组必须一致，别自己升级）

| 组件 | 版本 | 说明 |
|---|---|---|
| **JDK** | **25（LTS）** | 老师要求"21 以上"；23 已停止维护，改用当前 LTS 25 |
| **Node.js** | **25.9.0** | 老师要求"25 以上" |
| **Spring Boot** | **3.5.16** | 老师口径更新为 3.5；3.5.x 官方支持 JDK 17~25 |
| **Vue** | **3.x** | 实际 3.5.43 + Vite 8 |
| **Ant Design Vue** | **4.2.6** | 老师要求「vue3 + antD」；配套图标库 `@ant-design/icons-vue` 7.0.1 |
| **Redis** | 5.0.14.1 | Windows 移植版 |
| **Maven** | 3.9.x | 后端构建 |
| **Git** | 2.5x | 加装 TortoiseGit（小乌龟）做图形界面 |

> ⚠️ **JDK 全组统一装 25，不要自己换版本。**
> Spring Boot 3.5.x 官方支持 **JDK 17~25**，所以单看兼容性 21、23、25 都能跑；
> 但**全组必须锁同一个 25**——版本不一致就会出现「我这能跑、你那报错」的经典问题。
>
> **为什么不用 23？** JDK 23 是**非 LTS 的特性版**，Java 的特性版只维护 6 个月，
> **23 已于 2025-03-18 停止维护**。JDK 25 是 LTS（支持到 2030-09），同样满足老师的要求，
> 而且是 Spring Boot 3.5 支持范围内的最新版。
>
> 低于 JDK 17 会直接报 `Unsupported class file major version`。

## 一、装 Git + 小乌龟（图形化 Git）

| 步骤 | 操作 |
|---|---|
| 1 | 装 **Git for Windows** |
| 2 | 装完执行一次：`git config --global core.autocrlf true` |
| 3 | 设置身份（把名字邮箱换成你自己的）：<br>`git config --global user.name "你的名字"`<br>`git config --global user.email "你的邮箱"` |
| 4 | 再装 **TortoiseGit（小乌龟）**，顺序不能反——它只是外壳，本身不含 Git |
| 5 | 装小乌龟时如果问你 Git 装在哪，选你的 Git 目录（比如 `D:\git\Git`） |

### ⚠️ 小乌龟的 SSH 坑（几乎每个人都会踩）

小乌龟默认用 `TortoiseGitPlink` 做 SSH 客户端，它**读不了 OpenSSH 格式的密钥**。改成系统自带的最省事：

```
右键 → TortoiseGit → 设置(Settings) → 网络(Network)
  → SSH 客户端(SSH client) 改成：C:\Windows\System32\OpenSSH\ssh.exe
```

### 装中文界面

```
右键 → TortoiseGit → 设置(Settings) → 常规(General) → 语言(Language)
  → 选「中文(简体)」→ 确定
```

## 三、装开发环境

### 1. JDK 25

装完设置环境变量 `JAVA_HOME` 指向 JDK 目录，并把 `%JAVA_HOME%\bin` 加到 `PATH`。

验证（**新开的** CMD/PowerShell 里跑，只输入命令本身、别带任何注释）：

```
java -version
```

应显示 `openjdk version "25.0.2"`。

> ⚠️ **必须写全 `java -version`，不能写 `java -v`。**
> `-v` 只有 git / node / npm 支持，**Java 没有这个短选项**。敲 `java -v` 会输出：
> ```
> Unrecognized option: -v
> Error: Could not create the Java Virtual Machine.
> Error: A fatal exception has occurred. Program will exit.
> ```
> **这是命令打错了，不是环境坏了**（很多人第一次都被这两行红字吓到）。

### 2. Node.js 25

装完验证（同样只输入命令本身）：

```
node -v
npm -v
```

`node -v` 应显示 `v25.9.0`，`npm -v` 应显示 `11.x`。

**配 npm 国内镜像**（不然装前端依赖会卡死）：

```
npm config set registry https://registry.npmmirror.com
```

### 3. Redis（Windows 版）

Windows 官方没出 Redis，用社区移植版。下载解压后，目录里要能看到 `redis-server.exe`。

启动：**双击 `redis-server.exe`**（或目录里的启动脚本）。

看到这行才算成功：

```
Ready to accept connections
```

> ⚠️ **这个黑窗口不能关**，关了 Redis 就停。最小化就行。

### 4. Maven

解压即用。配国内镜像（阿里云）能省大量时间——在 `conf/settings.xml` 的 `<mirrors>` 里加：

```xml
<mirror>
  <id>aliyun</id>
  <mirrorOf>central</mirrorOf>
  <url>https://maven.aliyun.com/repository/public</url>
</mirror>
```

验证：`mvn -v`

> ⚠️ **别在 Git Bash 里跑 `mvn`**，会报 `ClassNotFoundException`（脚本兼容问题，不是 Maven 坏了）。
> 用 **PowerShell / CMD / IDEA** 里跑。

### 5. IntelliJ IDEA

装 **统一版**（2025.3 起 Community/Ultimate 已合并成单一版本）。

- 核心 Java + Spring Boot 开发功能**完全免费**，不用激活
- 打开时可能提示「Ultimate 试用 30 天」——**无视它**，30 天后自动降回免费版，功能照样够用

**安装选项**建议：勾「创建桌面快捷方式」，**不勾**「添加到 PATH」「文件关联」。

## 四、把项目跑起来（三步）

### 第 1 步：Redis（先起，不然后端连不上）

双击 Redis 目录里的 `redis-server.exe`，**保持黑窗口开着**。

### 第 2 步：后端

**用 IDEA（推荐）：**

| 步骤 | 操作 |
|---|---|
| 1 | IDEA 欢迎页点 **`打开(Open)`** |
| 2 | 选中 **`xinsheng\backend`** 这一层（里面要直接能看到 `pom.xml`，**别选根目录**） |
| 3 | 若弹「信任项目」→ 点**信任**（第二个「添加到 Defender 排除列表」的勾**建议去掉**，需要管理员权限且降低安全性） |
| 4 | 右下角弹「找到 Maven 构建脚本」→ 点 **`加载 Maven 项目`** |
| 5 | 等依赖下载完（**第一次几分钟**）。看不确定就去看 `视图 → 工具窗口 → Maven`，能展开「生命周期」就是好了 |
| 6 | `文件 → 项目结构 → 项目`：**SDK** 选你的 JDK 25，**语言级别**选 `25`（**不要选带「预览」的那个**，选带「文档注释」的） |
| 7 | 打开 `src/main/java/com/xinsheng/XinShengApplication.java`，点类名左边的**绿色三角 ▶** 运行 |

底部「运行」窗口出现这两行就成功：

```
Tomcat started on port(s): 8080 (http)
Started XinShengApplication in x.xxx seconds
```

**命令行方式**（在 `backend` 目录，用 PowerShell/CMD）：

```
mvn spring-boot:run
```

### 第 3 步：前端

在 `xinsheng\frontend` 目录：

```
npm install       # 首次才需要（会把 vue / vue-router / pinia / ant-design-vue 一起装好）
npm run dev
```

浏览器自动打开 `http://localhost:5173`。

> **antD 不用单独安装**。它已经写在 `frontend/package.json` 里，
> `npm install` 会自动拉下来（约 100~200 MB，国内源 1~3 分钟）。

页面上应该能看到 **两个菜单**：

| 页面 | 地址 | 作用 |
|---|---|---|
| 环境自检 | `/` | 验证「前端 → 后端 → Redis」链路 |
| antD 示例 | `/antd-demo` | 组件写法模板，写新页面**照这页抄** |

## 五、怎么确认"整条链路通了"

打开前端页面，它会自动请求后端。看到这个就是全通：

| 页面显示 | 含义 |
|---|---|
| `status: UP`、`javaVersion: 25.0.2`、`redis: OK -> ok` | ✅ 前端 → 后端 → Redis 三层全通 |
| `后端没连上` | 后端没启动，或端口不是 8080 |
| `redis: 连接失败` | Redis 黑窗口关了，重新双击启动 |

也可以直接测后端：浏览器访问 `http://localhost:8080/api/health`

## 六、分支开发与提交（老师课上要求）

### ★ 核心规则：别直接在 `main` 上改代码

| 角色 | 职责 |
|---|---|
| **组员** | 每人建**自己的分支**开发，改完**推送**到 GitHub |
| **组长** | 把组员分支**合并到 `main`**，合并后通知大家拉取 |

**分支命名**（与老师演示一致）：`Branch_<昵称><日期>`
例如 `Branch_rick0921`、`Branch_taffy0921`

### 组员：一轮开发的 8 步

| 步骤 | 操作（小乌龟，菜单是中文的） |
|---|---|
| 1 | 进到仓库文件夹**里面**，空白处右键 → `TortoiseGit` → **`同步...`** → 先点 **拉取** |
| 2 | 右键 → `TortoiseGit` → **`切换/检出...`** |
| 3 | Branch 里填自己的分支名 `Branch_你的昵称日期` |
| 4 | **勾上「创建新分支」** ← 关键，不勾会报「分支不存在」 |
| 5 | 点 **确定**，标题栏显示新分支名 = 成功 |
| 6 | 改代码 → 右键 → `TortoiseGit` → **`提交...`**（**只勾自己改的文件**）→ 写说明 → 提交 |
| 7 | **再点 `推送...`** ← 只提交不推送，GitHub 上什么都没有 |
| 8 | 群里说一声：`已推送 Branch_xxx，请组长合并` |

**命令行等价写法：**

```bash
git pull
git switch -c Branch_taffy0921        # 创建并切到自己的分支
# ... 改代码 ...
git add 你改的文件                     # 只加自己改的，别 git add .
git commit -m "feat: 完成了xxx功能"
git push -u origin Branch_taffy0921
```

### 组长：把组员分支合并到 main

| 步骤 | 操作 |
|---|---|
| 1 | `同步...` → 拉取（先确保自己是最新的） |
| 2 | `切换/检出...` → Branch 选 **`main`** → 确定 |
| 3 | 右键 → `TortoiseGit` → **`合并...`** → 选 `Branch_xxx` → 确定 |
| 4 | **推送** → 群里通知组员拉取 |

> 出现冲突（同一文件同一行两人都改了）时会提示，点「解决冲突」逐个文件手动取舍，改完再提交、推送。

### ⚠️ 三个必踩的坑

| 坑 | 后果 |
|---|---|
| 提交完**忘点「推送」** | 代码只在自己电脑上，GitHub 里没有，组长合并不了 |
| 切分支时勾了「**覆盖工作副本(强制)**」 | 未提交的改动被直接丢掉，找不回来 |
| 提交时**全勾**（`git add .`） | 把 `target/`、`node_modules/`、别人的改动一起带上，是冲突的主要来源 |

> 小贴士：对话框**标题栏**会写 `Git 提交 - TortoiseGit`，但**右键菜单项不带 `Git ` 前缀**
> （就叫「提交...」「推送...」「切换/检出...」）——别被这个不一致搞懵。

### commit message 格式

| 前缀 | 用途 | 例子 |
|---|---|---|
| `feat:` | 新功能 | `feat: 添加登录接口` |
| `fix:` | 修 bug | `fix: 修正分页参数越界` |
| `docs:` | 文档 | `docs: 补充接口说明` |
| `refactor:` | 重构（不改功能） | `refactor: 抽出公共响应类` |
| `chore:` | 杂项（配置、依赖） | `chore: 升级 spring boot 版本` |

## 七、常见问题

| 现象 | 原因 | 解决 |
|---|---|---|
| `mvn` 报 `ClassNotFoundException` | Git Bash 跑 mvn 脚本的兼容问题 | 换 PowerShell / CMD / IDEA |
| 后端端口不是 8080 | 有环境变量 `SERVER__PORT` 之类的劫持了 | 检查系统环境变量，删掉；`server.port` 优先级低于环境变量 |
| IDEA 里 `import` 全标红 | Maven 没导入完 / SDK 没设 | 点 Maven 面板的刷新图标重新同步；检查 `文件→项目结构→项目` 的 SDK |
| 前端 `npm install` 极慢或卡住 | 没配国内镜像 | `npm config set registry https://registry.npmmirror.com` |
| 页面组件样式全丢、按钮是灰白方块 | `main.js` 漏了 `import 'ant-design-vue/dist/reset.css'` 或没 `app.use(Antd)` | 对照仓库里的 `frontend/src/main.js` 补齐 |
| 用了 `<a-table>` 但页面报「未注册组件」 | 漏了 `app.use(Antd)`，或把 `main.js` 里的注册删了 | 同上；antD 已全量注册，模板里直接用，不用手动 import 组件 |
| 小乌龟克隆/推送提示认证失败 | 用的是 TortoiseGitPlink | 改成 `C:\Windows\System32\OpenSSH\ssh.exe`（见第一节） |
| 小乌龟提交了但 GitHub 上没有 | 只「提交」没「推送」 | 再点一次推送 |
| `Unsupported class file major version 69` | JDK 用了 26 或更高（超出 Spring Boot 3.5 支持范围） | 换成 JDK 25 |
| `Unsupported class file major version 67` | JDK 用了 23 或更低（超出 pom 里 release 25 的要求） | 换成 JDK 25 |
| `java -v` 报 `Unrecognized option` | Java 没有 `-v` 这个短选项 | 改敲 `java -version`，**不是环境坏了** |

## 九、antD 使用约定（前端必读）

### 1. 组件怎么用

antD 已经在 `main.js` 里**全量注册**（`app.use(Antd)`），**模板里直接用，不用逐个 import**：

```vue
<!-- 正确：直接用，angD 组件统一带 a- 前缀 -->
<a-button type="primary">查询</a-button>
<a-table :columns="columnsRef" :data-source="tableDataRef" />
```

| 写法 | 是否推荐 | 说明 |
|---|---|---|
| `<a-button>` / `<a-table>` | ✅ | antD 组件统一 `a-` 前缀 |
| 手动 `import { Button } from 'ant-design-vue'` | ⚠️ 可以但没必要 | 已全量注册，不用再 import |
| `<Button>` / `<Table>` 裸名 | ❌ | 没注册过，页面会报未注册组件 |

### 2. 项目约定（和编码规范 v2.8 对齐）

| 项 | 约定 |
|---|---|
| 中文化 | **不要**在页面里再包一层 `a-config-provider`，`App.vue` 已全局配好 `zh_CN` |
| 图标 | 从 `@ant-design/icons-vue` 引入：`import { PlusOutlined } from '@ant-design/icons-vue';` |
| 日期 | 用 `a-date-picker` 时加 `value-format="YYYY-MM-DD"`，拿到字符串，不用处理 dayjs 对象 |
| 变量命名 | `ref` 变量**必须以 `Ref` 结尾**（规范 §1.8）；方法动词开头、属性后置，如 `loadTaskList()` |
| 注释 | **每个变量、每个方法上面都要写一行注释**（规范 §1.8） |
| 引号分号 | js 里字符串用**单引号**；每行结尾**加分号**（规范 §1.8） |
| 文件命名 | 页面文件用**小写中划线**：`antd-demo-view.vue`、`user-list.vue`（❌ 不要 `UserList.vue`） |

### 3. 照抄模板

`/antd-demo` 页已经把「查询表单 + 表格分页 + 弹窗表单」整套写好了，
写业务页面**直接照抄改字段**即可：`frontend/src/views/antd-demo-view.vue`

> **将来要压打包体积**（课设不需要）：把 `main.js` 的 `app.use(Antd)` 换成
> `unplugin-vue-components` + `AntDesignVueResolver` 按需引入，**页面代码一个字都不用改**。
